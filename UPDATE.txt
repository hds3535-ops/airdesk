AirDesk 첫 화면 로딩 개선 업데이트

적용 방법
1. ZIP을 풀어 app, lib 폴더 안의 파일들을 기존 AirDesk GitHub 저장소의 같은 경로에 덮어쓰세요.
2. 새 파일도 모두 업로드해야 합니다. 특히 app/workspace-client.tsx, app/fonts.tsx, lib/workspace-data.ts, lib/workspace-types.ts를 빠뜨리지 마세요.
3. 커밋 후 Vercel의 새 배포가 Ready 상태인지 확인하고 사이트를 새로고침하세요.
4. Supabase SQL 재실행, 패키지 설치 변경, 환경변수 추가는 필요 없습니다.

변경 내용
- 정상 로그인 상태에서는 첫 HTML 응답에 작업과 고객 데이터를 함께 표시합니다.
- 화면이 열린 뒤 로그인 확인과 데이터 요청을 연달아 하던 대기 단계를 줄였습니다.
- 서버에서 이미 데이터를 받았다면 브라우저에서 같은 데이터를 다시 요청하지 않습니다.
- 로그인 정보가 만료된 경우에는 데이터 API에서 갱신과 데이터 로딩을 함께 처리합니다.
- 외부 글꼴은 화면이 표시된 뒤 불러옵니다. 처음에는 기본 글꼴이 잠깐 보일 수 있습니다.
- 작업 삭제 기능과 기존 서버 키 오류 안내 개선도 포함됩니다.
- 모든 데이터 조회는 관리자 인증 이후에만 수행하며, 고객 데이터를 공용 캐시나 로컬 스토리지에 저장하지 않습니다.

주의 사항
- 이 ZIP은 기존 Vercel 프로젝트에 적용하는 업데이트입니다. 왼쪽 ChatGPT 미리보기 사이트에는 자동 반영되지 않습니다.
- 인터넷, Vercel 서버 시작 시간, Supabase 응답 시간에 따른 대기는 여전히 발생할 수 있습니다.
- 실제 배포 서버의 속도는 아직 측정하지 않았습니다. 배포 후에도 지연이 크면 Vercel 함수 지역과 Supabase 지역, 네트워크 응답 시간을 확인해야 합니다.
- 기존 저장소를 비우지 말고 위 파일들만 같은 경로로 덮어쓰세요.
